# Python-BMI-Calculator
A simple BMI Calculator built in Python using a Jupyter Notebook. This script collects user input, calculates Body Mass Index (BMI), and classifies the result based on standard BMI ranges.

- Accepts user input for name, weight (lbs), and height (inches)
- Calculates BMI using the formula:
  BMI = (weight * 703) / height²
- Rounds the BMI value to one decimal place
- Classifies BMI into categories:
  Underweight
  Normal weight
  Overweight
  Obese
  Severely obese
  Morbidly obese
- Prints a personalized result message
